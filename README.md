# For Snigdha

This repository contains a small, hand-coded personal website (a proposal) created by Boni.

What's included:
- index.html — the single-page site
- style.css — styles with responsive tweaks
- script.js — light interactivity, typewriter, lightbox, confetti
- images/ — three photos used in the gallery
- favicon.svg — a small heart favicon

Quick steps to publish with GitHub Pages:
1. Go to this repository's Settings → Pages.
2. Set the source to the `main` branch and the root folder (/).
3. Save. The site will be available at: `https://boniroy689-oss.github.io/For-snigdha/` in a few minutes.

If you want, I can also enable automatic deploy via GitHub Actions or add a custom domain (provide the domain and I will add a CNAME file).
